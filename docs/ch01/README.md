# 🧱 第 1 章：打造加一的身体 — Python 快速起步

## 故事：加一需要一具"身体"

加一的大脑之后会由 LLM（大语言模型）来充当，可现在她连动一下手指都做不到。她需要一具能接收指令、执行动作、和外部世界打交道的身体。在 AI 应用开发里，这具身体就是 Python。

---

## 做 AI 应用需要哪些 Python 概念

你不用把 Python 学透再开始，掌握下面这些就够起步，其余的遇到再学。

| 概念 | 白话解释 | 在 Agent 项目里的角色 |
|------|----------|----------------------|
| 变量与基本类型 | 给一份数据起个名字，数据可以是文字、数字、真假值 | 存放 API Key、模型名、温度参数、用户输入 |
| 字符串 | 一段文字 | 拼装发给模型的 Prompt，清洗模型返回的文本 |
| 列表 list | 按顺序排好的一串数据 | 保存对话历史、工具清单、检索到的文档片段 |
| 字典 dict | "键 → 值"的对照表 | 表示一条消息（角色 + 内容）、一个工具的描述、请求配置 |
| 函数 | 把一段操作打包，起名后反复调用 | 封装"调用模型""搜索网页"等动作；Agent 的每个工具本质上是一个函数 |
| 类与对象 | 把数据和操作它的函数装在一起的模板 | 看懂 SDK 里的 Client 对象，组织 Agent、Memory 等模块 |
| 循环与条件判断 | 重复执行、按情况分支 | Agent 核心循环："思考 → 调工具 → 看结果 → 决定是否继续" |
| 异常处理 try / except | 出错时接住错误，程序不直接崩溃 | 处理网络超时、API 限流、模型返回格式不对 |
| JSON | 一种通用的文本数据格式，长得像字典 | 模型 API 的请求和返回、工具调用参数都用它传递 |
| 文件读写 | 从硬盘读内容、往硬盘写结果 | 读取知识库文档（RAG），保存日志和对话记录 |
| HTTP 请求库 | 让程序访问网络接口的工具包 | 调用 LLM API 和各种外部服务 |
| 时间处理 | 获取当前时间、计算时间差 | 记录日志时间戳、统计接口耗时 |
| 虚拟环境 | 每个项目一套独立的 Python 和依赖库 | 避免不同项目的库版本互相冲突 |

## 这些概念怎么组合起来

一个最简单的对话助手，用到的就是上表里的几块：

```text
用户输入（字符串）
   │
   ▼
加入对话历史（列表，每条消息是一个字典）
   │
   ▼
调用模型的函数（HTTP 请求 + JSON + try/except）
   │
   ▼
取出回复文本 → 打印给用户 → 回到循环开头
```

对应的伪代码：

```python
历史 = []
循环:
    用户输入 = 读取输入()
    如果 用户输入 == "退出": 结束
    历史.添加({"角色": "用户", "内容": 用户输入})
    尝试:
        回复 = 调用模型(历史)      # 第 2 章换成真实的 API 调用
    出错时:
        回复 = "网络出错了，请重试"
    历史.添加({"角色": "助手", "内容": 回复})
    打印(回复)
```

本章你先让这个结构跑起来，"调用模型"那一步暂时用一个直接复述用户输入的函数代替。

## 🐍 环境准备步骤

1. 安装 Python 3.10 或更高版本。
2. 新建一个项目文件夹。
3. 在文件夹里创建虚拟环境。
4. 激活虚拟环境，终端提示符前出现 `(venv)` 表示成功。
5. 用 pip 安装需要的第三方库（例如 HTTP 请求库）。
6. 新建一个 `.py` 文件，写好后在终端运行。

具体命令随操作系统不同略有差异，可以直接问 AI："在 Windows / macOS 上怎么创建并激活 Python 虚拟环境？"

> **加一的第一个产出：** 一个能在终端里来回对话的模拟助手。它现在只会复述你的话，但程序已经跑起来了。

## 🤖 向 AI 提问

> **概念不理解：** "请用生活类比解释 Python 中的字典（dict）是什么？我刚开始学编程。"

> **需要练习：** "请给我出 5 道 Python 基础练习题，难度递增，围绕字符串处理和列表操作，每道题附带预期输出。"

**Prompt 模板：**

```
角色：你是一个擅长类比教学的编程导师
任务：用不超过 200 字解释 [概念名称]
受众：零编程基础的成人学习者
要求：使用一个生活场景的比喻，不要直接抄定义
```

**三遍学习法：**

1. 让 AI 讲解概念。
2. 让 AI 出 3–5 道练习题。
3. 写完代码后让 AI 审查："请审查我的代码，指出可以改进的地方。"
