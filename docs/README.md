# 📖 序章：加一的诞生

## 故事背景

2018 年，研究者 **PlutoKeating** 在白板上写下一个名字：**加一（plusOne）**。意思是每天进步一点，每次迭代多一分能力。

他想让加一学会三件事：听懂人话、像主厨先翻菜谱库再做菜那样查资料、动手调用工具办事。
